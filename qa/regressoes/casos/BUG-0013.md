# BUG-0013 — Janela fechada continua consumindo respostas

- Status: VALIDADO_AUTOMATICAMENTE. Severidade: média. Data: 2026-10-19. Origem: suíte Qt integrada.

Uma janela fechada mantida no mesmo QApplication continuava com o QTimer ativo e
marcava replies de outra janela como processadas. O teste integrado encontrou um
SUCCESS com plan_id correto já consumido enquanto a janela solicitante aguardava.
Não foi demonstrado esse cenário em duas janelas interativas do usuário; o runtime
normal tem instância única. O contrato de fechamento continuava incorreto.

RED: runtime/reports/audit-poll-close-red.xml. Proteção permanente:
tests/ui/test_rough_cut_lifecycle.py::test_closed_window_stops_polling_and_does_not_steal_another_reply.
Correção: parar timer e impedir varredura após fechamento aceito, conservando a
varredura se uma operação ativa impedir o fechamento. Gate final aprovado, conforme seção abaixo.
